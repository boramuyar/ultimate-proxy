# Security

Please do not report security problems in public issues.

Report them privately through GitHub instead: on the repository's **Security** tab, choose
**Report a vulnerability**. Include what an attacker could do, the version or commit, and the steps
or config to reproduce it. You will get an answer as soon as a maintainer has looked at it, and a fix
is released before the problem is made public.

Only the latest release gets security fixes.
